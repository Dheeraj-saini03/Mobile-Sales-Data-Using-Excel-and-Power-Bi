# 📱 Mobile Sales Dashboard | Power BI & Excel

## 📌 Project Overview

This project is an interactive **Mobile Sales Dashboard** built using **Microsoft Power BI** and **Microsoft Excel**. It provides a comprehensive analysis of mobile phone sales, helping users monitor sales performance, customer purchasing trends, payment methods, and brand-wise performance through dynamic visualizations.

This dashboard was created as part of my learning journey under the guidance of **Satish Dhawale Sir**.

## 🚀 Key Features

- 📈 Total Sales, Transactions, Average Sales & Total Quantity KPIs
- 🗺️ City-wise Sales Analysis using Map Visual
- 📅 Monthly Quantity Sold Trend
- 📱 Brand-wise Units Sold Comparison
- 💳 Payment Method Distribution
- 📆 Day-wise Sales Performance
- 📋 Detailed Brand-wise Sales Table
- 🎯 Interactive Slicers for:
  - Month Filter
  - Mobile Model Filter
